User Flow:
==========

1. /start → Select Language → Verify Channel Join
2. "Sell My Group" → Enter Group Link → Add Bot as Admin
3. Bot Reads Metadata → Calculates Price → Shows Analysis
4. User Uploads Screenshot → Sent to Admin
5. Admin Reviews → Approves/Rejects
6. If Approved → User Provides Payment Info
7. Admin Marks Paid → User Notified → Complete

Admin Flow:
===========

1. Receive Notification (screenshot + details)
2. /panel → View Pending Submissions
3. Inline Buttons:
   - View Screenshot
   - Confirm Transfer → Moves to awaiting_payment
   - Reject → Request reupload with reason
4. User Provides Payment Info
5. Mark as Paid (double confirm) → User Notified

Technology Stack:
=================

🐍 Python 3.11+
🤖 Aiogram v3.4.1 (async Telegram bot framework)
💾 SQLite + aiosqlite (async database)
🌐 aiohttp (async HTTP for webhook)
🖼️ Pillow (image validation)
📦 python-dotenv (environment management)
☁️ Render.com (deployment platform)

Security Features:
==================

✅ Rate limiting (1 action/second)
✅ Input validation (all user inputs)
✅ Image validation (type + size)
✅ Admin restrictions (ADMIN_ID check)
✅ SQL injection prevention (parameterized queries)
✅ No local file storage (Telegram file_id)
✅ Error logging (LOG_CHANNEL_ID)
✅ Environment variables (all secrets)
✅ Channel verification (required before access)

Commands Reference:

Environment Variables:
======================

Required:
  BOT_TOKEN       - Telegram bot token (@BotFather)
  ADMIN_ID        - Admin user ID (@userinfobot)
  CHANNEL_ID      - Brand channel (@TeleTradeET)
  BASE_URL        - Production URL (webhook)

Optional:
  LOG_CHANNEL_ID  - Error logging channel
  DATABASE_URL    - Database path (default: sqlite:///data.db)
  WEBHOOK_PATH    - Webhook endpoint (default: /webhook)
  PORT            - Web service port (default: 8080)
